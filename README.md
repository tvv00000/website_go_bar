# Projekti idee ja seletus
Projekti idee on landing page "GO BAR" rakenduse jaoks. Sama teema on ka kasutajaliidese esteetika kursusel, ehk disaini arendus käis mõlema kursuse ajal käsi-käes.
Lehe üldine disain on rohkem mängulik kui tõsine. Peamine kasutatav värv on oranž. [Värvidele link](https://i.imgur.com/b1norSU.png)


# Projekti eesmärk
Leht keskendub rakenduse tutvustamisele, call to action väljendub rakenduse allalaadimise/konto loomise kujul, millele saab ligi ka navigatsiooniriba kaudu.
Selle järgi on ka lehe eesmärk tutvustada tulevasele kasutajale lihtsasti arusaadavalt rakendust ning saada kasutajaid rakendust alla laadima ja kontosid looma.
